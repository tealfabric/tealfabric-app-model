# Changelog

All notable changes to **Tealfabric App Model** are documented here.

ProcessFlow **interface** (contract) history lives in [`docs/processflow/interface/CHANGELOG.md`](docs/processflow/interface/CHANGELOG.md). Broader ProcessFlow doc history from the merge source is in [`docs/processflow/PROCESSFLOW_CHANGELOG.md`](docs/processflow/PROCESSFLOW_CHANGELOG.md).

## [0.1.0] — 2026-11-02

### Added

- Initial public **Tealfabric App Model** release combining:
  - Full-stack app template (Vite + React SPA, WebApp shell, ProcessFlow BFF router/handlers, deploy script)
  - ProcessFlow authoring docs, interface v1.0.4, `spec/`, `examples/`, and `reference/`
- Product paths and names use **app-model** (`/app-model`, `CDN/app-model`, `app-model-*` processes, `app_model_*` DataPool schemas).
- Root `VERSION` (`0.1.0`) and `INTERFACE_VERSION` (`1.0.4`).
